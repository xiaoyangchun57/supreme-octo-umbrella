# 代码变更验证检查清单

## 代码修改前检查

- [ ] 已阅读相关的原始VB源代码文件
- [ ] 已理解原始代码的核心逻辑
- [ ] 已识别需要修改的代码段
- [ ] 已确认修改范围不会影响其他模块

## 代码修改中检查

- [ ] 修改内容与原始代码逻辑一致
- [ ] 已考虑边界情况和异常处理
- [ ] 代码风格与现有代码一致
- [ ] 已添加必要的注释说明

## 代码修改后检查

- [ ] 已使用相同输入数据进行对比测试
- [ ] 现代码输出与原始代码输出一致
- [ ] 已记录验证过程和结果
- [ ] 已分析并处理所有差异
- [ ] 测试覆盖了正常情况和边界情况
- [ ] 代码已通过语法检查

## 验证记录检查

- [ ] 验证记录包含输入数据描述
- [ ] 验证记录包含输出对比结果
- [ ] 验证记录包含差异分析（如有）
- [ ] 验证记录已归档保存

## 差异处理检查

- [ ] 所有差异都已识别
- [ ] 差异原因已分析清楚
- [ ] 非预期差异已修复
- [ ] 预期差异已记录说明
- [ ] 已重新验证修复后的代码
